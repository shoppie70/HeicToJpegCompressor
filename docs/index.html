初回だけ、
macOSの許可が必要です。

このアプリはApple Developer IDによる署名・Apple公証を行っていないため、macOSが初回起動をブロックします。GitHub Releasesなど信頼できる配布元から取得したDMGであることを確認した場合のみ、次の手順で許可してください。
