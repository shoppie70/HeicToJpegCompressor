A VERY SMALL macOS APP

HEICをJPEGへ
縮小圧縮するだけ.app

変換サイトも、Squooshも、
もう開かない。

iPhoneの写真をMacに持ってきたあと、「JPEGにして、ちょうどいいサイズにして、軽くする」という毎回の作業を、画像を放り込むだけにするmacOSアプリです。

AFTER

いまは、これだけ。

HEIC IMG_1234.HEIC iPhoneから来た、そのままの写真
↓ ここへ放り込む 複数枚でもOK
JPEG IMG_1234_compressed.jpg そのまま使いやすい画像
JPEG 最大長辺 1980px 品質 85% metadata削除 複数枚対応

ONE JOB. DONE WELL.

すること。

01

JPEGにする

HEIC / HEIF / JPEG / PNGを、扱いやすいJPEGへ。

02

ちょうどよく縮める

初期値は最大長辺1980px。小さい画像は無理に拡大しません。

03

軽くする

初期品質は0.85。見た目と容量のバランスを取ります。

04

余計な情報を残さない

GPS、撮影日時、カメラ情報などのmetadataを初期設定で削除します。

NOT AN IMAGE EDITOR

しないこと。

  • トリミングしない。
  • フィルターをかけない。
  • AI補正しない。
  • クラウドへ送らない。
  • アカウントを作らせない。
  • 毎回、設定を聞かない。

高機能にするより、毎回の30秒を消したい。

WHY I BUILT IT

自分が本当に使うものを、
初めてのSwiftで。

Swiftも、macOSネイティブアプリ開発も未経験でした。

でも「自分が毎回やっていて、本当に面倒な作業」が見つかった。なら、その自動化をMacアプリ開発の題材にすればいい。

高機能な画像変換ソフトを作ることが目的ではありません。日常に残っていた小さな無駄を、一つ消すためのアプリです。
