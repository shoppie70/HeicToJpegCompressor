FOR macOS · OPEN SOURCE

画像を、
落とすだけ。

JPEGへ変換し、
圧縮・リサイズします。

ただそれだけを行う、極めてシンプルなアプリです。
機能が一つしか無いからこそ、便利です。

GitHubで見る → 3ステップでわかる ↓

変換ボタンも、保存ダイアログも、
プレビュー編集もありません。

必要な処理を、ドロップだけで。

THE FLOW

1枚でも、
まとめてでも。

  1. 01

    DROP

    HEIC、JPEG、PNGをアプリ画面またはDockアイコンへドロップ。

  2. 02

    CONVERT

    JPEG化、圧縮、リサイズを、今の設定で自動実行。

  3. 03

    DONE

    元画像と同じフォルダに、すぐ使えるJPEGを保存。

BY DESIGN

少ない機能。
迷わない体験。

01

Web向けに整える

JPEG品質と長辺サイズを選ぶだけ。小さい画像を拡大することはありません。

02

プライバシーを守る

位置情報、撮影日時、カメラ情報などのmetadataを初期設定で削除します。

03

元画像を守る

元ファイルは変更・上書きしません。変換結果は別のJPEGとして保存します。

AT A GLANCE

必要なことを、
きちんと。

  • 入力HEIC / HEIF / JPEG / PNG
  • 出力JPEG
  • リサイズ長辺 1280〜2560px / 原寸
  • 品質0.0〜1.0（初期値 0.85）
  • 実装Swift / SwiftUI / Apple標準Framework

MAKE THE ROUTINE DISAPPEAR

変換を、
作業にしない。
