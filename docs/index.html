ONE SIMPLE FLOW

やることは、ひとつ。

  1. 01

    画像を落とす

    HEIC、JPEG、PNGを、アプリ画面またはDockアイコンへ。

  2. 02

    自動で変換

    JPEG化、圧縮、リサイズを設定どおりにまとめて実行。

  3. 03

    すぐに使える

    元画像と同じフォルダに、Web向けJPEGを保存します。

SMALL, ON PURPOSE

余計なことは、しません。

WEB READY

JPEGに変換

品質は調整可能。初期値は、見た目と容量のバランスを考えた0.85です。

RIGHT SIZE

大きすぎる画像を整える

長辺を指定サイズまで縮小。小さい画像を無理に拡大することはありません。

PRIVATE BY DEFAULT

metadataを削除

位置情報、撮影日時、カメラ情報などを、初期設定で出力ファイルに残しません。

ORIGINALS STAY SAFE

元画像は触らない

変換結果は別ファイルとして保存。元画像を変更・上書きすることはありません。

入力HEIC / JPEG / PNG
出力JPEG
対応複数ファイル
フレームワークApple標準のみ
